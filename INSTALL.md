# Сборка и установка без Mac (GitHub Actions + AltStore)

Эта инструкция — как получить из этого кода собственный `.ipa` и поставить его на iPhone, **не имея Mac**.

## Что вам понадобится

1. **Аккаунт GitHub** (бесплатный).
2. **Apple ID** (можно бесплатный).
3. На Windows: **GitHub Desktop** (https://desktop.github.com) и **AltStore** (https://altstore.io) или **Sideloadly** (https://sideloadly.io).

`api_id` и `api_hash` не хранятся в репозитории. Для сборки через GitHub Actions обязательно добавьте их как секреты репозитория — без них workflow остановится до начала сборки.

## Шаг 1. Форкнуть исходный репозиторий

> Важно: код содержит git-подмодули (rlottie, tgcalls, webrtc, tdlib и др.), которые подтягиваются при сборке. Поэтому нужно именно **форкнуть** репозиторий, а не заливать файлы как новый репозиторий.

1. Откройте https://github.com/ichmagmaus111/ghostgram → нажмите **Fork** → создайте форк в своём аккаунте (публичный — иначе лимиты на macOS-раннеры).

## Шаг 2. Применить мои правки (безопасность + ребрендинг + ключи)

1. Установите **GitHub Desktop** и залогиньтесь, затем **File → Clone repository → выберите свой форк** → Clone (запомните папку, куда он склонирован).
2. Скачайте архив `ghostgram-changes.zip` (идёт в комплекте с этим проектом).
3. Распакуйте его и **скопируйте содержимое с заменой файлов** в папку, куда склонирован форк (файлы в архиве лежат по тем же путям, что и в репозитории).
4. Откройте GitHub Desktop — он покажет изменённые файлы. Напишите любой комментарий и нажмите **Commit to main**, затем **Push origin**.

## Шаг 3. Добавить секреты GitHub

Откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

| Имя | Значение |
|---|---|
| `API_ID` | ваш api_id |
| `API_HASH` | ваш api_hash |
| `BUNDLE_ID` (необязательно) | уникальный id, например `com.yourname.ghostgram`; если не задан, используется `com.ghostgram.app` |

Workflow проверяет формат `API_ID` и `API_HASH` и использует их только во время сборки. Не записывайте эти значения в исходный код или публичные конфиги. Если API hash уже публиковался, безопаснее создать новую пару на my.telegram.org и сохранить новую в Secrets.

## Шаг 4. Запустить сборку

1. В репозитории откройте вкладку **Actions**.
2. Выберите workflow **CI** → **Run workflow** → **Run workflow**.
3. Сборка Telegram тяжёлая (30–90+ минут). Дождитесь зелёной галочки.

## Шаг 5. Скачать .ipa

На вкладке Actions откройте завершённый запуск → внизу **Artifacts** или на странице релиза (создаётся автоматически) скачайте **`Telegram.ipa`**.

## Шаг 6. Установить на iPhone

### Вариант A — AltStore (Windows)
1. Установите AltStore на Windows, подключите iPhone кабелем (понадобится iTunes/Apple Devices).
2. AltStore в трее → **Install AltStore on iPhone** (введите Apple ID).
3. На iPhone: AltStore → **My Apps → «+»** → выберите скачанный `.ipa`.
4. После установки: **Настройки → Основные → VPN и управление устройством → доверить разработчику**.

### Вариант B — Sideloadly (Windows)
1. Откройте Sideloadly, перетащите `.ipa`, введите Apple ID, **Start**.

## Шаг 7. Продление подписи

Бесплатная подпись Apple ID живёт **7 дней**. AltStore продлевает её автоматически, если iPhone и ПК в одной сети (или по кабелю) и запущен AltServer. Либо переустанавливайте раз в неделю.

## Если сборка упала

- `Xcode_XX.app not found` → в `.github/workflows/build.yml` поменяйте `runs-on: macos-15` на раннер, где есть Xcode из `versions.json`.
- Ошибка в подмодулях (`submodule ... not found`) → проверьте `.gitmodules` (я уже исправил сломанные относительные ссылки на публичные зеркала `ali-fareed/*`).
- Ошибка `Missing required GitHub Actions secrets` → проверьте, что `API_ID` и `API_HASH` добавлены в Secrets именно того репозитория, где запускается workflow.
